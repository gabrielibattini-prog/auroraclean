# Aurora Clean

Estrutura inicial de um site institucional responsivo, preparada com abordagem mobile-first.

## Estrutura

```text
.
├── index.html
├── README.md
└── src/
    ├── assets/       # Imagens, ícones e outros arquivos estáticos
    ├── scripts/      # JavaScript da interface
    └── styles/       # Folhas de estilo
```

## Como visualizar

Abra `index.html` no navegador. O projeto não depende de ferramentas de build nesta etapa.
